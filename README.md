# Калькулятор рейтинга фильмов

Скрипт на Python для обработки JSON-файла с отзывами на фильм.
Программа вычисляет среднюю оценку фильма, считает количество уникальных пользователей, а также обрабатывает битые отзывы и дубликаты.

## Как запустить:
1. Установите Python.
2. Запустите `python main.py`.
Результат сохранится в файл `report.txt`.
